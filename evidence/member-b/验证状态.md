```powershell
node .\tests\member-b\terminal-bridge.cjs `
  'D:\develop\Java\jdk-17.0.18\bin\java.exe' `
  'D:\candelete\member-b-tools\database-final.properties'
```

在浏览器打开 http://127.0.0.1:33085，点击启动正式 Main，按行输入菜单编号和参数。使用完成后主菜单 0 退出 Java，并用 Ctrl+C 关闭辅助服务器。该工具复用本机已有 Node.js，本轮没有为截图安装 Node 或前端依赖。
