# 教师与课程概念设计

教师和课程分别保存可独立维护的基础资料，教学班负责描述某学期由某教师教授某门课程的事实。B 拥有前两个实体，C 拥有教学班及其外键；下图中的教学班只作为跨模块上下文。

| 实体 | 属性 | 候选键及依据 |
|---|---|---|
| 教师 teacher | id、teacher_no、name | id 唯一标识记录；teacher_no 按教务编号规则唯一且非空 |
| 课程 course | id、course_code、name、credits | id 唯一标识记录；course_code 按课程编码规则唯一且非空 |

主键选择 id，编号为备用候选键。姓名和课程名均可能重复，不据字段名称猜测唯一性。学分是课程固有属性，不是教师或教学班的属性。

教师到教学班是一对多：一位教师可以暂不开课，也可承担多个班；每个班恰有一位教师。课程到教学班也是一对多：一门课程可以尚未开班，也可开多个班；每班恰对应一门课程。教师与课程的授课事实通过教学班间接形成多对多，不再增加重复关系表，也不在 course 上添加 teacher_id。

学生与教学班的多对多由 A 的 enrollment 实体实现，属于全组概念设计的另一部分，B 不在本模块重新设计。
